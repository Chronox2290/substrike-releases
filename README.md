# Substrike releases

Public downloads for Substrike, and the complete corresponding source for the GPL components it ships.

## FFmpeg

Substrike bundles its own minimal build of FFmpeg 9.0.1 (GPL version 3 or later). Each FFmpeg release here contains the Windows build (`substrike-ffmpeg-<version>-win64.zip`), its complete corresponding source (`substrike-ffmpeg-<version>-source.tar`, with every library tarball, the build script and the configure line) and `SHA256SUMS.txt`. The source archive's `README.txt` explains how to rebuild it.

Details: https://substrike.app/source
